Wat is dit portfolio?

Dit portfolio laat mijn voortgang en projecten zien.

De website heeft drie secties: Projecten en Leeruitkomsten.

In de sectie 'Projecten' zie je alles waaraan ik heb gewerkt, zoals het Branding project, het Create That UX project, het Development project en mijn persoonlijke project.

Daarnaast vertel ik in 'Projecten' ook over het proces van het maken van dit portfolio.

De sectie 'Leeruitkomsten' toont mijn behaalde leeruitkomsten van dit semester, met daarbij welk project bij elke leeruitkomst hoort.

In deze sectie 'Over Mijn Portfolio' vertel ik meer over mezelf, mijn interesses en mijn studieloopbaan.

Je leest waarom ik bepaalde keuzes heb gemaakt in het ontwerp en de structuur van dit portfolio.

Ook leg ik uit waar de visuele inspiratie vandaan komt en hoe ik mijn persoonlijke stijl in de site heb verwerkt.
