Leeruitkomsten

Interactive Media Products

Tijdens het maken van mijn portfolio heb ik nagedacht over hoe mijn werk niet alleen mooi maar ook interactief aanvoelt. Het is belangrijk dat de gebruiker niet alleen kijkt, maar ook iets doet. Bijvoorbeeld door op knoppen te klikken die naar een andere pagina leiden, of bijvoorbeeld animaties die afspelen als je erover heen gaat met je muis, denk aan de effecten die je krijgt als je over knoppen gaat op deze website.

Functionaliteiten zoals de lightbox voor het vergroten van afbeeldingen en meescrollende navigatie zijn keuzes die ik bewust maakte om het gebruiksvriendelijk te maken, zodat gebruikers niet steeds zelf linksboven hoeven te klikken om terug naar de pagina te gaan.

Development & Version Control

Deze hele site is gemaakt met HTML, CSS en JavaScript. Ik gebruik GitHub om versies bij te houden, fouten te kunnen terugdraaien en m’n voortgang inzichtelijk te maken. Ook gebruik ik Github Pages om deze website online te zetten, ik ben momenteel ook een domein aan t regelen zodat het adres geen github adres meer is.

De lightbox-functionaliteit werkte in eerste instantie niet op GitHub Pages — ik heb moeten debuggen, aanpassen en testen tot het klopte. Precies het soort probleem dat je alleen leert oplossen door te dóén.

Iteratief Ontwerpen

De designtool die ik het afgelopen semester vooral veel heb gebruikt is Figma. Het is een goed werkende tool waar in je in principe alles in kan maken (van wireframes tot prototypes).

Bij elk groepsproject vroeg ik regelmatig om feedback van medestudenten, docenten en zelfs vrienden. Dit hielp mij om mijn ontwerpen te verbeteren en te zorgen dat ik niet vast kwam te zitten in mijn eigen ideeën.

Persoonlijk Leiderschap

Feedback is voor mij essentieel geworden. Niet alleen binnen school, maar ook van buitenstaanders — vrienden, familie, mensen die niks met design doen. Juist dat hielp mij verder. Ik heb 2 tests afgenomen, een Brandtest voor het Branding Project en een test voor mijn portfolio (layout en design keuzes)

Daarnaast probeer ik steeds meer werk te maken dat echt bij mij past. Mijn stijl, mijn interesses (zoals muziek & games), en hoe ik die terug laat komen in kleur, opmaak en sfeer.
