Leeruitkomsten

LO 1 – Interactive Media Products

Tijdens het maken van mijn portfolio heb ik nagedacht over hoe mijn werk niet alleen mooi maar ook interactief aanvoelt. Bijvoorbeeld door knoppen, animaties en hover-effecten zoals je nu op deze website ervaart.

Functionaliteiten zoals de lightbox en smooth scrolling verbeteren de ervaring. Ik heb ook gebruikersfeedback ontvangen over bijvoorbeeld de leesbaarheid van teksten, zoals bij het Branding Project (Brandtest). Verder heb ik feedback die gegeven is door docenten en opdrachtgcevers verwerkt in mijn werk. Dit is terug te zien in designs die ik na feedback van cardan aangepast heb , verder is deze hele website interactief en heb ik hem ge-usertest bij familie en vrienden, dit is te zien bij deze tests: User Test 1 Portfolio en User Test 2 Portfolio.

LO 2 – Development & Version Control

Deze site is volledig gebouwd met HTML, CSS en JavaScript. Ik gebruik GitHub om versies bij te houden, en host het via GitHub Pages. Ook heb ik tijdens het development project gewerkt met GitHub.

Ik heb geleerd om bugs op te sporen en op te lossen, zoals de lightbox die aanvankelijk niet werkte op GitHub Pages. Dit proces is goed zichtbaar in mijn commits en repo, te vinden in mijn GitHub Portfolio Repository en Development Repository.

Ik organiseerde mijn werk met Trello en werkte samen in teamverband. Tijdens de projecten hebben we onderzoek gedaan, taken verdeeld en resultaten besproken met de opdrachtgever.

Feedback en communicatie met de docenten, groepsgenoten en opdrachtgevers waren belangrijk. Dit zie je terug in de Reflectie van het UX-project en het Branding project. Hieronder zijn ook de gebruikte trello borden te vinden.

LO 5 – Persoonlijk Leiderschap

Ik vroeg actief feedback van klasgenoten, vrienden en familie. Op basis van hun opmerkingen over o.a. leesbaarheid en structuur heb ik aanpassingen gedaan. Ik heb gereflecteerd op mijn werk en mezelf. Ik heb punten laten zien die minder goed gingen, zoals mijn communicatie met docenten en medestudenten.

Mijn interesses in muziek en gaming zie je terug in de stijl van mijn werk. Ook heb ik reflecties geschreven na projecten. Ik heb vooruit gekeken naar het volgende semester en doelen gesteld.
